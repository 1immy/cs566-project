Overview

Single-photon (SPAD) cameras capture thousands of binary frames per second, where each pixel only records whether a photon arrived — a single frame is nearly meaningless, and a clean image only emerges from aligning and merging a burst. This project tests whether history-rejection heuristics from real-time temporal anti-aliasing (TAA) in game engines — neighborhood clamping, motion-adaptive blending — improve classical align-and-merge reconstruction of single-photon bursts, especially under fast motion and disocclusion. We evaluate on the Single Photon Challenge benchmark, co-organized by Prof. Gupta's lab.

Proposal (Sep 29, 2026)

Problem statement

Reconstructing clean images from single-photon bursts under motion, and testing whether TAA-style history rejection improves the classical align-and-merge pipeline compared to naive averaging and hierarchical block alignment baselines.

Motivation

The standard SPAD reconstruction pipeline (estimate motion, align, merge) is structurally identical to TAA in real-time rendering — a cross-domain connection we haven't found explored elsewhere. The project also builds directly on Prof. Gupta's own quanta burst photography work and benchmark.

Approach

Implement a baseline (naive averaging + hierarchical block alignment), then a TAA-augmented pipeline (neighborhood clamping, motion-adaptive blend weights, per-pixel confidence map), and compare both on Single Photon Challenge scenes and visionsim-generated motion sweeps.
